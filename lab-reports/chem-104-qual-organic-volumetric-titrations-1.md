## Exp 1: Identification of Alcohols (CH₃OH & C₂H₅OH) | 12.08.26

**Aim:** Identify methanol and ethanol by the iodoform test.

**Key idea:** Only ethanol has the CH₃–CH(OH)– group.

```
 Ethanol: CH₃–CH₂–OH     → has CH₃CH(OH)–  → CHI₃ ↓ yellow  (+ve)
 Methanol: CH₃–OH        → no CH₃CH(OH)–   → no ppt.        (–ve)
```

**Reactions**
```
I₂ + 2NaOH → NaOI + NaI + H₂O
C₂H₅OH + NaOI → CH₃CHO + NaI + H₂O
CH₃CHO + 3NaOI → CI₃CHO + 3NaOH
CI₃CHO + NaOH → CHI₃↓ + HCOONa

Overall: C₂H₅OH + 4I₂ + 6NaOH → CHI₃↓ + HCOONa + 5NaI + 5H₂O
```
**Confirmation (oxidation)**
```
C₂H₅OH --[O]--> CH₃CHO --[O]--> CH₃COOH   (vinegar smell)
CH₃OH  --[O]--> HCHO   --[O]--> HCOOH     (pungent)
5CH₃OH + 2KMnO₄ + 3H₂SO₄ → 5HCHO + K₂SO₄ + 2MnSO₄ + 8H₂O
```

**Apparatus:** Test tubes, water bath (60 °C), dropper, burner.
**Chemicals:** Samples A, B; I₂/KI; 10% NaOH; dil. H₂SO₄; dil. KMnO₄.

**Procedure**
```
1 mL sample → +2 mL NaOH → +I₂ dropwise (faint colour stays)
→ warm 60 °C, 2–3 min → cool → look for yellow ppt.
```

**Observation**

| Sample | I₂/NaOH | Inference |
|---|---|---|
| A | Yellow ppt., antiseptic smell | Ethanol |
| B | No ppt. | Methanol |

**Result:** A = C₂H₅OH, B = CH₃OH.

**Precautions**
- Use clean, dry tubes (acetone and ethanol traces give false +ve).
- Add I₂ only until a faint colour persists.
- Warm gently.
- Add NaOH before I₂.
- Waft vapour, don't sniff directly.

## Exp 2: Identification of Carboxylic Acids | 25.08.26

**Aim:** Identify HCOOH, (COOH)₂, CH₃COOH, C₆H₅COOH.

```
 HCOOH        HOOC–COOH       CH₃–COOH       C₆H₅–COOH
 H–C(=O)OH    (oxalic)        (acetic)       (benzene ring–COOH)
 (has –CHO H → reducing)
```

**Reactions**
```
Common:   RCOOH + NaHCO₃ → RCOONa + H₂O + CO₂↑

Formic:   HCOOH + 2[Ag(NH₃)₂]OH → 2Ag↓ + (NH₄)₂CO₃ + 2NH₃ + H₂O   (silver mirror)

Oxalic:   5H₂C₂O₄ + 2KMnO₄ + 3H₂SO₄ → K₂SO₄ + 2MnSO₄ + 10CO₂↑ + 8H₂O
          (COOH)₂ + CaCl₂ → CaC₂O₄↓ (white)

Acetic:   CH₃COOH + C₂H₅OH --conc.H₂SO₄--> CH₃COOC₂H₅ + H₂O   (fruity)
          3CH₃COOH + FeCl₃ → Fe(CH₃COO)₃ (red) + 3HCl
          Fe(CH₃COO)₃ + 2H₂O --boil--> Fe(OH)₂(CH₃COO)↓ (buff) + 2CH₃COOH

Benzoic:  3C₆H₅COOH + FeCl₃ → Fe(C₆H₅COO)₃↓ (buff) + 3HCl
          Heat solid → sublimes
```

**Apparatus:** Test tubes, water bath, watch glass, litmus.
**Chemicals:** Neutral FeCl₃, NaHCO₃, Tollens' reagent, CaCl₂, KMnO₄/H₂SO₄, conc. H₂SO₄, C₂H₅OH.

**Flow**
```
Litmus red + NaHCO₃ fizz → –COOH present
   ├─ Tollens' mirror ........... HCOOH
   ├─ KMnO₄ decolourised (hot), CaCl₂ white ppt. ... (COOH)₂
   ├─ FeCl₃ red → buff on boiling; ester smell ..... CH₃COOH
   └─ FeCl₃ buff ppt.; sublimes ................... C₆H₅COOH
```

**Observation**

| Test | HCOOH | (COOH)₂ | CH₃COOH | C₆H₅COOH |
|---|---|---|---|---|
| Litmus | Red | Red | Red | Red |
| NaHCO₃ | CO₂ | CO₂ | CO₂ | CO₂ |
| Tollens' | Mirror | – | – | – |
| KMnO₄ | Decolourised | Decolourised | – | – |
| CaCl₂ | – | White ppt. | – | – |
| FeCl₃ | see note | – | Red → buff | Buff ppt. |

**Result:** Samples = HCOOH, (COOH)₂, CH₃COOH, C₆H₅COOH.

**Precautions**
- Prepare Tollens' fresh and discard it (it can form explosive AgCNO).
- Use neutral FeCl₃.
- Add conc. H₂SO₄ slowly.
- Heat gently when subliming.
- Rinse tubes between tests.

> **Note:** Your original table listed formic acid with neutral FeCl₃ as "pale yellow (no ppt.)". Most textbooks give formic acid a **red colour** with neutral FeCl₃, like acetic acid, and oxalic acid a pale yellow solution. Match whatever your lab manual says.

## Exp 3: Na₂CO₃ in Washing Soda | 01.09.26

**Aim:** Find % Na₂CO₃ by titration with standard HCl.

**Reactions**
```
Stage 1 (phenolphthalein, pH 8.3):  Na₂CO₃ + HCl → NaHCO₃ + NaCl
Stage 2 (methyl orange, pH 3.5–4):  NaHCO₃ + HCl → NaCl + H₂O + CO₂↑

Overall:  Na₂CO₃ + 2HCl → 2NaCl + H₂O + CO₂↑

CO₃²⁻ --H⁺--> HCO₃⁻ --H⁺--> H₂CO₃ → H₂O + CO₂
```

**Apparatus:** Burette, pipette (25 mL), conical flask, volumetric flask (250 mL), tile.
**Chemicals:** Washing soda (1.325 g), 0.1 N HCl, methyl orange.

**Setup**
```
   [ HCl in burette ]
          │
          ▼
   [ 25 mL Na₂CO₃ + methyl orange ]  on white tile
   End point: yellow → faint orange/pink
```

**Procedure**
```
1.325 g → 250 mL stock → pipette 25 mL → +2–3 drops MO (yellow)
→ titrate with HCl → permanent orange/pink → repeat (±0.1 mL)
```

**Observation**

| Trial | Initial | Final | HCl (mL) |
|---|---|---|---|
| 1 | 0.0 | 12.5 | 12.5 |
| 2 | 0.0 | 12.6 | 12.6 |
| 3 | 0.0 | 12.5 | 12.5 |

Concordant volume = **12.5 mL**

**Calculation**
```
N₁V₁ = N₂V₂
N₂ = (0.1 × 12.5) / 25 = 0.05 N

Strength = 0.05 × 53 = 2.65 g/L
In 250 mL = 2.65 × 250/1000 = 0.6625 g
% Na₂CO₃ = (0.6625 / 1.325) × 100 = 50.0 %
```

**Result:** Na₂CO₃ = **50.0 %**

**Precautions**
- Rinse the burette with HCl and the pipette with sample.
- Read the meniscus at eye level.
- Use only 2–3 drops of indicator.
- Go dropwise near the end point.
- Use a white tile.

## Exp 4: Standardization of KMnO₄ with Oxalic Acid | 06.09.26

**Aim:** Find the normality of KMnO₄ using standard oxalic acid.

**Why standardise?** KMnO₄ is impure and decomposes slowly, so it is not a primary standard.

**Reactions**
```
Oxidation:  H₂C₂O₄ → 2CO₂ + 2H⁺ + 2e⁻              (×5)
Reduction:  MnO₄⁻ + 8H⁺ + 5e⁻ → Mn²⁺ + 4H₂O        (×2)

2KMnO₄ + 5H₂C₂O₄ + 3H₂SO₄ → K₂SO₄ + 2MnSO₄ + 10CO₂↑ + 8H₂O
```
```
MnO₄⁻ (purple) ──→ Mn²⁺ (colourless)      Mn²⁺ = autocatalyst
Self-indicator: permanent faint pink = end point
```

**Apparatus:** Burette, pipette (10 mL), conical flask, water bath, thermometer.
**Chemicals:** 0.1 N (COOH)₂·2H₂O, KMnO₄ (~0.1 N), dil. H₂SO₄.

**Procedure**
```
10 mL oxalic acid + 5 mL dil. H₂SO₄ → heat to 60–70 °C
→ titrate with KMnO₄ (slow at first, then fast)
→ permanent pink (30 s) = end point
```

**Observation**

| Trial | Initial | Final | KMnO₄ (mL) |
|---|---|---|---|
| 1 | 0.0 | 9.8 | 9.8 |
| 2 | 0.0 | 9.9 | 9.9 |
| 3 | 0.0 | 9.8 | 9.8 |

Concordant volume = **9.8 mL**

**Calculation**
```
N₁V₁ = N₂V₂
N₂ = (0.1 × 10) / 9.8 = 0.102 N

Strength = 0.102 × 31.6 = 3.22 g/L
```

**Result:** N(KMnO₄) = **0.102 N**

**Precautions**
- Keep the temperature at 60–70 °C.
- Add KMnO₄ slowly at first.
- Use only dil. H₂SO₄, never HCl (Cl⁻ is oxidised).
- Use a glass-stopcock burette (KMnO₄ attacks rubber).
- Read the upper meniscus.

## Exp 5: Estimation of Fe²⁺ with KMnO₄ | 15.09.26

**Aim:** Find the strength of Fe²⁺ (Mohr's salt) using standardised KMnO₄.

**Reactions**
```
Oxidation:  Fe²⁺ → Fe³⁺ + e⁻                       (×5)
Reduction:  MnO₄⁻ + 8H⁺ + 5e⁻ → Mn²⁺ + 4H₂O

Ionic:  MnO₄⁻ + 5Fe²⁺ + 8H⁺ → Mn²⁺ + 5Fe³⁺ + 4H₂O

Molecular:  2KMnO₄ + 10FeSO₄ + 8H₂SO₄
            → K₂SO₄ + 5Fe₂(SO₄)₃ + 2MnSO₄ + 8H₂O
```
```
Fe²⁺ (pale green) → Fe³⁺ (yellow)
Permanent faint pink = END POINT
Room temperature (no heating)
```

**Apparatus:** Burette, pipette (10 mL), conical flask, tile.
**Chemicals:** KMnO₄ (0.102 N), Fe²⁺ solution (100 mL), dil. H₂SO₄.

**Procedure**
```
10 mL Fe²⁺ + 5 mL dil. H₂SO₄ → titrate at once with KMnO₄
→ permanent pink (30 s) → repeat
```

**Observation**

| Trial | Initial | Final | KMnO₄ (mL) |
|---|---|---|---|
| 1 | 0.0 | 10.5 | 10.5 |
| 2 | 0.0 | 10.6 | 10.6 |
| 3 | 0.0 | 10.5 | 10.5 |

Concordant volume = **10.5 mL**

**Calculation**
```
N₁V₁ = N₂V₂
N₂ = (0.102 × 10.5) / 10 = 0.107 N

Strength = 0.107 × 56 = 6.00 g/L
In 100 mL = 6.00 × 100/1000 = 0.60 g
```

**Result:** Fe²⁺ = **0.107 N = 6.00 g/L (0.60 g in 100 mL)**

**Precautions**
- Don't heat (Fe²⁺ oxidises in air).
- Use only H₂SO₄, never HCl.
- Titrate promptly after acidifying.
- Rinse the burette and pipette first.
- Stop at the first permanent pink (over-titrating gives a positive error).
