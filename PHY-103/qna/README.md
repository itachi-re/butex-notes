## 1 · Solved final exams, 2017–2023

All questions from Part A and Part B for every year, solved. Several theory questions repeat across years (Gauss's law, Wheatstone bridge, Hall effect, Carnot cycle, …), so each such derivation is written out in full **once** and given a code such as **[D-7]**. When the question comes back in a later year, that year's solution says "Same as [D-n]" and gives the final result. Numericals are solved in full for every year, because the data changes.

The bank exists in three forms, with the same content:

| Form | Best for | Notes |
|---|---|---|
| [`phy-103-qna/`](phy-103-qna/README.md) | Reading on GitHub | Split into 14 pages so each stays small enough for GitHub to render every equation |
| [`phy-103-qna-2017-2023.md`](phy-103-qna-2017-2023.md) | Searching, exporting | One file (~95 KB), equations written as LaTeX (`$$ … $$`) |

## 🎯 Suggested study flow

1. **Learn** a topic from the chapter in [`phy-103-kinetic-theory-of-gases-qna.md`](phy-103-kinetic-theory-of-gases-qna.md) or from the derivation pages (parts 01–08).
2. **Check frequency.** The repeated-topics table in part 14 and the priority map in the CT prep file show what the papers keep asking.
3. **Practise** from the year pages (parts 09–13) or the 1422 question list, without looking at the answers.
4. **Compare** with the worked answers. When a solution says "Same as [D-n]", open the matching derivation.
5. **Finish** with the formula sheet and checklist in part 14, or the one-page sheet in the CT prep file.

## 🏷️ File naming

