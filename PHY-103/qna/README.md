### 3. Exam-code 1422 question bank

A separate set, kept in three files:

- **Questions** — [`phy-103-question-bank-1422.md`](phy-103-question-bank-1422.md): the question list to attempt first.
- **Answers** — [`phy-103-question-bank-1422-answers.md`](phy-103-question-bank-1422-answers.md): worked answers.
- **Grouped (`-g`)** — [`phy-103-question-bank-1422-g.md`](phy-103-question-bank-1422-g.md): the questions regrouped by topic (the file is headed *Physics-II Question Bank (2014–2022)*).

## 🎯 Suggested study flow

1. **Attempt** the questions for a topic from the 1422 set or from a year page, without looking at solutions.
2. **Compare** with the worked answer; when a solution cites a code like `D-27`, open the matching derivation page.
3. **Revise** the derivations (parts 01–08), then finish with the formula sheet (part 14) the day before the exam.
4. **Repeat** across years. Questions recur, so the year pages show which derivations come up most often.

## 🏷️ File naming

Files follow one scheme across `PHY-103`:

```text
phy-103-<topic>-<type>-<year>.md
```

- all lowercase, words joined with hyphens (no underscores)
- the year or year range is left out when a file has none
- the split bank uses a numeric prefix (`01-`, `02-`, …) to fix the reading order
