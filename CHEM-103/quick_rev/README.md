# CHEM-103 Quick Revision: File Index

Chemistry-II (CHEM-103), BUTEX. Quick-revision material: class tests, topic notes, solved previous-year questions (2015-2023) and whole-course references.

Files are grouped by a category prefix, so they sort together on GitHub. Use the **Go to file** search (`t`) and type a prefix such as `pyq-04` or `notes-` to jump straight to a group.

## Naming convention

```
chem-103-<category>-<topic>-<type>-vYYMMDD-N.md
```

| Part | Meaning |
|---|---|
| `chem-103` | Course code |
| `<category>` | `ct`, `ct-2`, `notes`, `pyq-NN`, `ref` (see below) |
| `<topic>` | Topic in lowercase, hyphenated |
| `<type>` | `ques-solve`, `qna`, `qb`, `prep`, `notes`, etc. |
| `vYYMMDD` | Date the file was made |
| `N` | Revision number, starting at 0 |

When a topic has two versions, the higher date/revision is the newer one.

## Categories

| Prefix | What it holds |
|---|---|
| `ct-` / `ct-2-` | Class test (CT) questions, answers and prep |
| `notes-` | Topic notes, one-shot revision, exam prep |
| `pyq-01` to `pyq-07` | Previous-year question solves, 2015-2023, in syllabus order |
| `ref-` | Whole-course references: question bank, Q&A, asset index |
