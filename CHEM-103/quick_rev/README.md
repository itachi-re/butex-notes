# CHEM-103 Quick Revision: File Index

Chemistry-II (CHEM-103), BUTEX. Quick-revision material: class tests, topic notes, solved previous-year questions (2015-2023) and whole-course references.

Use the **Go to file** search (`t`) on GitHub and type a topic keyword such as `carbonyl`, `dyes` or `grignard`, or a type such as `ques-solve` or `notes`, to jump straight to a group.

## Naming convention

```
chem-103-<topic>-<type>-vYYMMDD-N.md
```

| Part | Meaning |
|---|---|
| `chem-103` | Course code |
| `<topic>` | Topic in lowercase, hyphenated. May include a year range (`2016-2023`) or `ct` / `ct2` for class tests |
| `<type>` | `ques-solve`, `qna`, `qb`, `prep`, `notes`, `oneshot`, `asset-index` |
| `vYYMMDD` | Date the file was made |
| `N` | Revision number, starting at 0 |

When a topic has two versions, the higher date/revision is the newer one.
