# CHEM-103 Visual Asset Library — Index & Usage Guide

This companion document indexes the 97 SVG assets in `chem103-visual-assets.zip` against the 2017–2023 solved question bank, and records the one scientific correction applied per the source-accuracy rules.

All paths below are relative to the `assets/` folder at the root of the zip. To embed an asset in a markdown note, use a path relative to that note's location, e.g. from a notes file at `notes/organic/reactions.md`:

```md
![SN2 mechanism](../../assets/mechanisms/sn2-mechanism.svg)
```

---

## ⚠️ Correction note (per source-accuracy hierarchy)

**2022 Question 1(d)** as scanned reads: *"Show that E₂ reaction is first order but E₁ 2nd order reaction."* This is chemically reversed — mechanistically, **E1 is first-order** (`Rate = k[RX]`, two steps via a carbocation) and **E2 is second-order** (`Rate = k[RX][Base]`, one concerted step). The original wording is preserved verbatim in the question bank; the diagrams (`mechanisms/e1-mechanism.svg`, `mechanisms/e2-mechanism.svg`) show the scientifically correct assignment, not the reversed wording. The 2021 and 2020 versions of this same question are worded correctly and needed no correction.

No other scientific inconsistencies were identified in the source during asset production.

### Known gaps (not fabricated — explicitly flagged per the task's own instructions)
- **Congo red**: rendered as a labeled schematic rather than a full skeletal structure, because I could not confidently reconstruct its exact SMILES from memory and preferred an honest simplification over a risk of an inaccurate structure.
- **Fructofuranose stereochemistry**: the Haworth sketch is labeled "representative configuration" — I am highly confident in the D-glucose Fischer/Haworth assignments (verified against the well-established textbook pattern) but less certain of every wedge direction for the fructose furanose ring, so I flagged it rather than assert false precision.
- **Not built**: dedicated summary sheets for amino-acid reactions, carbohydrate reactions, and dye chemistry (the general reactions-index partially substitutes); a few secondary named-reaction variants and some individual structure diagrams (e.g., separate 1°/2°/3° amine structure set, some additional dye intermediates) from the original ~150-item wishlist were not created due to scope.
- All 97 delivered files passed automated XML validity, render-without-error, and text/box-overflow checks — this was verified mechanically, not just visually.
