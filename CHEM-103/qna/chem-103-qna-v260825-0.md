## QUESTION 1 — 5 MARKS

### 1°, 2°, 3° Amines
Amines are classified by the number of H atoms of NH₃ replaced by alkyl/aryl groups:

| Type | Formula | Example |
|------|---------|---------|
| Primary (1°) | R–NH₂ | CH₃NH₂ (methylamine) |
| Secondary (2°) | R₂NH | (CH₃)₂NH (dimethylamine) |
| Tertiary (3°) | R₃N | (CH₃)₃N (trimethylamine) |

### Separation of 1°, 2°, 3° Amines — Hinsberg's Method
**Reagent:** benzenesulfonyl chloride (C₆H₅SO₂Cl) + KOH

```
RNH2   + C6H5SO2Cl  --[KOH]-->  C6H5SO2NHR   (soluble in alkali — acidic N–H)
R2NH   + C6H5SO2Cl  --[KOH]-->  C6H5SO2NR2   (insoluble in alkali — no N–H)
R3N    + C6H5SO2Cl  -->  No reaction (remains as free amine)
```

**Procedure:**
1. Treat mixture with C₆H₅SO₂Cl/KOH.
2. **3° amine** – unreacted, extract with dil. HCl → basify with NaOH.
3. **1° sulfonamide** – dissolves in excess alkali (acidic NH) → separate → hydrolyze with dil. HCl → regenerate 1° amine.
4. **2° sulfonamide** – insoluble solid, filter → hydrolyze with HCl → regenerate 2° amine.

### (i) Sandmeyer and Gattermann Reactions
Both replace the diazonium group (–N₂⁺) by –Cl, –Br, or –CN.

**Sandmeyer reaction:**
```
ArN2+Cl-  --[CuCl / CuBr / CuCN, Δ]-->  ArCl / ArBr / ArCN  +  N2
```
*Example:* C₆H₅N₂⁺Cl⁻ --[CuCl, Δ]--> C₆H₅Cl + N₂

**Gattermann reaction:**
```
ArN2+Cl-  --[Cu powder / HCl or HBr, Δ]-->  ArCl / ArBr  +  N2
```
*Example:* C₆H₅N₂⁺Cl⁻ --[Cu/HCl]--> C₆H₅Cl + N₂

**Difference:** Sandmeyer uses cuprous salts (CuCl, CuBr, CuCN); Gattermann uses Cu powder directly with the corresponding acid — a modification avoiding preformed cuprous salts.

### (ii) Coupling and Sulfa Drug Reaction

**Coupling reaction** — diazonium salt + phenol/aromatic amine → azo dye (–N=N– linkage), at 0–5 °C.

```
C6H5N2+Cl-  +  C6H5OH  --[NaOH, weakly alkaline, 0–5°C]-->
      C6H5-N=N-C6H4-OH(p)  +  HCl
```
(p-hydroxyazobenzene — orange dye)

**Sulfa drug (sulfonamide) synthesis** from aniline:

```
C6H5NH2
   --[(CH3CO)2O]-->  C6H5NHCOCH3            (acetanilide, protects –NH2)
   --[ClSO3H]-->      p-CH3CONH-C6H4-SO2Cl
   --[NH3]-->          p-CH3CONH-C6H4-SO2NH2
   --[dil. HCl, hydrolysis/deprotection]-->
                       p-H2N-C6H4-SO2NH2    (Sulfanilamide)
```

### (iii) Hofmann and Curtius Degradation
Both convert –CONH₂/–COCl (n carbons) → –NH₂ (n−1 carbons), i.e., loss of one carbon.

**Hofmann bromamide degradation:**
```
RCONH2  --[Br2 / NaOH]-->  [RNCO]  --[H2O]-->  RNH2  +  CO2
```
*Example:* CH₃CONH₂ --[Br₂/NaOH]--> CH₃NH₂

**Curtius degradation:**
```
RCOCl  --[NaN3]-->  RCON3 (acyl azide)
RCON3  --[Δ]-->      RNCO  +  N2
RNCO   --[H2O]-->    RNH2  +  CO2
```
*Example:* CH₃COCl → CH₃CON₃ --[Δ]--> CH₃NCO --[H₂O]--> CH₃NH₂

Both proceed via an **isocyanate (R–N=C=O)** intermediate with migration of R from carbon to nitrogen.

## QUESTION 2 — 5 MARKS

### (i) Definitions with Examples
- **Protein:** High-MW polymer of amino acids joined by peptide bonds; e.g., insulin, hemoglobin.
- **Amino acid:** Compound with both –NH₂ and –COOH groups; H₂N–CHR–COOH; e.g., glycine (R = H), alanine (R = CH₃).
- **Essential amino acid:** Not synthesized in the body, must come from diet; e.g., Leucine, Valine, Lysine.
- **Non-essential amino acid:** Synthesized by the body; e.g., Glycine, Alanine, Serine.
- **Zwitterion:** Dipolar form of amino acid, H₃N⁺–CHR–COO⁻, net charge zero.
- **Isoelectric point (pI):** pH at which amino acid exists wholly as zwitterion, net charge = 0, no migration in electric field.
- **Peptide linkage:** Amide bond (–CO–NH–) formed between –COOH of one amino acid and –NH₂ of another with loss of H₂O.

### (ii) Synthesis of α-Amino Acid — Strecker Synthesis
```
RCHO  --[NH3]-->  RCH(NH2)OH  --[HCN]-->  RCH(NH2)CN  --[H3O+, hydrolysis]-->  RCH(NH2)COOH
```
*Example:* CH₃CHO --[NH₃]--> --[HCN]--> CH₃CH(NH₂)CN --[H₃O⁺]--> CH₃CH(NH₂)COOH (**Alanine**)

### (iii) End-Group Analysis of Peptides

**N-terminal analysis:**
- **Sanger's method:** Peptide + 1-fluoro-2,4-dinitrobenzene (FDNB) → DNP-peptide → acid hydrolysis → DNP-amino acid (yellow, identified chromatographically).
- **Edman degradation:** Peptide + phenyl isothiocyanate (PITC) → PTC-peptide → mild acid → PTH-derivative of N-terminal residue released without breaking rest of chain (repeatable for sequencing).

**C-terminal analysis:**
- **Carboxypeptidase enzyme method:** Enzymatically cleaves and releases C-terminal residues one at a time.
- **Hydrazinolysis (Akabori method):** Peptide + NH₂NH₂, 100 °C → all residues except C-terminal converted to amino acid hydrazides; C-terminal residue released as free amino acid.

### (iv) Synthesis of Gly-Ala Peptide

**Step 1 – Protect amino group of glycine:**
```
H2N-CH2-COOH  --[(CH3)3C-O-CO-Cl, Boc-Cl]-->  (CH3)3C-O-CO-NH-CH2-COOH   (Boc-Gly-OH)
```

**Step 2 – Activate carboxyl group:**
```
Boc-Gly-OH  --[DCC, dicyclohexylcarbodiimide]-->  Boc-Gly-O- (activated ester)
```

**Step 3 – Coupling with alanine ester:**
```
Boc-Gly-O-  +  H2N-CH(CH3)-COOC2H5  -->
      Boc-NH-CH2-CO-NH-CH(CH3)-COOC2H5
```
(peptide bond –CO–NH– formed between Gly-COOH and Ala-NH₂)

**Step 4 – Deprotection:**
```
--[CF3COOH, removes Boc]--> H2N-CH2-CO-NH-CH(CH3)-COOC2H5
--[dil. NaOH, ester hydrolysis]--> H2N-CH2-CO-NH-CH(CH3)-COOH   (Gly-Ala)
```

### (v) Essential vs Non-Essential Amino Acids

| Essential | Non-Essential |
|---|---|
| Not synthesized by the body | Synthesized by the body |
| Must be obtained from diet | Not required from diet |
| e.g. Leucine, Valine, Lysine, Phenylalanine, Threonine | e.g. Glycine, Alanine, Serine, Glutamic acid |
| Deficiency causes growth/health disorders | No deficiency issues normally |

## 📌 Last-Minute Revision

**Amines:**
- 1°/2°/3° amine = 1/2/3 H of NH₃ replaced by R group.
- Hinsberg's reagent: **C₆H₅SO₂Cl/KOH** — 1° soluble in alkali, 2° insoluble solid, 3° unreacted.
- **Sandmeyer:** ArN₂⁺Cl⁻ + CuCl/CuBr/CuCN → ArX/ArCN
- **Gattermann:** ArN₂⁺Cl⁻ + Cu/HCl → ArCl
- **Coupling:** ArN₂⁺Cl⁻ + phenol (NaOH, 0–5°C) → azo dye (–N=N–)
- **Sulfa drug:** Aniline → acetanilide → ClSO₃H → NH₃ → hydrolysis → Sulfanilamide
- **Hofmann:** RCONH₂ --[Br₂/NaOH]--> RNH₂ (via RNCO)
- **Curtius:** RCOCl --[NaN₃]--> RCON₃ --[Δ]--> RNCO --[H₂O]--> RNH₂

**Amino Acids/Peptides:**
- Zwitterion: H₃N⁺–CHR–COO⁻; pI = pH of zero net charge.
- **Strecker synthesis:** RCHO → (NH₃) → (HCN) → RCH(NH₂)CN → (hydrolysis) → RCH(NH₂)COOH
- **N-terminal:** Sanger's (FDNB) / Edman (PITC)
- **C-terminal:** Carboxypeptidase / Hydrazinolysis
- **Peptide synthesis order:** Protect (Boc) → Activate (DCC) → Couple → Deprotect (acid/hydrolysis)
