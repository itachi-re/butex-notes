## Suggested study route

1. **Read the priority table** at the top of the main file and note the 🔴 *must-prepare* blocks.
2. **Solve every 🔴 question on paper** once: mechanical properties, crystal structures, fracture/fatigue/creep, corrosion, iron-steel, polymers.
3. **Practise the numericals** (stress, elongation, tube diameter, punching force, APF, density).
4. **Heat treatment:** go through the latest heat-treatment sheet, then the CT-2 sheet for question patterns.
5. **Finish with** the formula sheet, common mistakes and viva questions (Part B of the main file).

## Naming convention

```text
<subject-code>-<topic>-<type>-v<YYMMDD>-<N>.md
```

| Part | Meaning | Example |
|---|---|---|
| `subject-code` | course code | `ipe-101` |
| `topic` | what it covers | `heat-treatment` |
| `type` | kind of document | `quick-revision`, `ct2-prep`, `exam-prep` |
| `vYYMMDD` | date made | `v260930` = 30 Sep 2026 |
| `N` | revision number, starting at 0 | `-1` |

Example: `ipe-101-heat-treatment-quick-revision-v260930-1.md`

## Adding a new file

1. Name it with the convention above (new revision of an old file → same name, higher `N`).
2. Put figures in `../../assets/` and reference them as `../../assets/<file>.svg`.
3. Add a row to the **Contents** table here.
