# IPE-102 Viva Quick Revision
**Lathe · Shaper · Grinding**

---

## 1. Lathe Machine

**One-liner:** Workpiece rotates, single-point tool is fixed and fed → removes material as chips. Called the *"mother of all machines"*.

### Parts & Functions

| Part | Function |
|---|---|
| **Bed** | Base of the machine; all parts mount on it. Cast iron, with ways (slides) |
| **Headstock** | Transmits power; supports the main spindle; houses speed-change gears |
| **Tailstock** | Movable on bed ways; holds dead center, drill bits; has handwheel |
| **Carriage** | Between headstock and tailstock; supports, guides and feeds the tool |
| **Saddle** | H-shaped casting on the ways; carries cross-slide, compound rest, tool post |
| **Cross slide** | Moves tool at right angles to the work axis (facing, depth of cut) |
| **Compound rest** | On top of cross-slide; swivels for angles and short tapers |
| **Tool post** | Holds the tool holder; cutting-edge height adjustable |
| **Apron** | Hangs in front of the saddle; has gears/clutches and the **split nut** for thread cutting |
| **Chuck** | Holds short, large-diameter or irregular work |
| **Feed rod** | Gives the carriage longitudinal power feed (turning) |
| **Lead screw** | Used for **threading** (job rotation + tool linear movement together) |
| **Spindle** | Hollow shaft; bore size sets the max bar stock |

### Operations
| Operation | Key point |
|---|---|
| Turning | Reduces outer diameter (most common) |
| Taper turning | Cylinder → cone |
| Shoulder turning | Stepped diameters |
| Facing | Machines the end; tool ⟂ to axis |
| Thread cutting | Internal/external threads |
| Parting | Deep groove to cut off a piece |
| Chamfering | Bevels the end |
| Knurling | Diamond-pattern grip on surface |
| Drilling | Drill held in tailstock |

**Specs:** Power 1–2 HP · Speed 45–3000 rpm · Weight 1500–3500 lb
**Merits:** high finish, high speed, saves time and money.
**Demerits:** high initial cost, needs skilled operator, not economical for small-batch CNC.
**Safety:** know controls first · never run without guards · stop before measuring/cleaning/adjusting · remove chuck key · clear chips with a brush.

### Lathe Viva Q&A
1. **Why is the lathe called the mother of all machines?** It is the oldest machine tool and can perform many operations; other machine tools evolved from it.
2. **What moves in a lathe, the tool or the job?** The job rotates; the single-point tool is fed.
3. **Feed rod vs lead screw?** Feed rod → normal turning feed. Lead screw → thread cutting (via split nut).
4. **What is the function of the apron?** Transfers motion from feed rod/lead screw to the carriage; contains the split nut.
5. **Why is a compound rest used?** To turn angles and short tapers.
6. **What holds the work in a lathe?** Between centers, chuck, or faceplate.
7. **What is facing?** Machining the end face, tool fed at right angles to the axis.
8. **Parting vs turning?** Parting cuts the piece off; turning only reduces diameter.
9. **Why remove the chuck key after use?** It can fly out when the spindle starts, causing injury.
10. **What determines max bar size through the headstock?** Spindle bore diameter.

## 2. Shaper Machine

**One-liner:** Workpiece fixed, tool reciprocates on the ram. **Cuts on forward stroke, no cut on return.** Uses *quick-return mechanism*. Produces flat and angular surfaces.

### Parts & Functions

| Part | Function |
|---|---|
| **Base** | Carries all machine loads |
| **Column** | Supports the ram as it moves back and forth |
| **Table** | Box casting with T-slots; moves cross-wise (cross-feed) and vertically (elevation screw) |
| **Cross rail** | On the column; carries the saddle; moves vertically/horizontally |
| **Ram** | Reciprocates; carries the tool head |
| **Tool post** | Positions and holds the cutting tool |
| **Tool head** | Holds tool firmly; gives vertical and angular movement (clapper box) |
| **Vice** | Two-jaw clamp that holds the workpiece |

### Operations
| Operation | Key point |
|---|---|
| Horizontal cutting | Table moves cross-wise relative to ram stroke |
| Vertical cutting | Internal surfaces, keyways, slots, grooves |
| Inclined cutting | Angled cut using table and vertical slide |
| Angular cutting | Cut at any angle other than 90° |

**Specs:** Power 3 HP · Max 140 strokes/min · Weight ~1250 kg
**Merits:** low tool cost, work held easily, flat/angular surfaces.
**Demerits:** low cutting speed, only one tool at a time.
**Applications:** keyways, gear teeth, dovetail slides, internal splines, flat surfaces.
**Safety:** don't reach across table while ram moves · don't adjust while running · no stripped bolts for clamps · never leave running unattended · no bare hands/compressed air for chips.

### Shaper Viva Q&A
1. **Which mechanism does a shaper use?** Quick-return motion mechanism.
2. **Which stroke is the cutting stroke?** Forward stroke.
3. **Why a quick-return?** Return stroke is idle, so it is made faster to save time.
4. **What reciprocates, the tool or the job?** The tool (on the ram); the job is fixed.
5. **Role of the clapper box?** Lets the tool lift on the return stroke to avoid dragging/damage.
6. **How is the table moved?** Cross-wise by cross-feed rod, vertically by elevation screw.
7. **What can a shaper make?** Flat surfaces, keyways, slots, grooves, dovetails, gear teeth.
8. **Why can't a shaper cut fast?** Cutting happens only on the forward stroke with a single-point tool.
9. **Why not clear chips by hand or air?** Injury risk from sharp chips and flying debris.
10. **Shaper vs lathe?** Shaper: tool moves, job fixed, flat surfaces. Lathe: job rotates, tool fixed, cylindrical surfaces.

## 3. Grinding Machine

**One-liner:** Removes material with **bonded abrasive grains** (undefined cutting edges) on a rotating wheel. Gives high finish and accuracy.

### Parts & Functions

| Part | Function |
|---|---|
| **Bed** | Bottom, horizontal base |
| **Column** | Vertical pillar carrying the wheel head |
| **Headstock** | Houses live center; grips the job |
| **Tailstock** | Houses dead center; supports the job |
| **Work table** | Guides and holds the workpiece |
| **Grinding wheel** | Main tool; removes material for finish/smoothness |
| **Motor** | Drives the wheel via belt and pulley |
| **Job post** | Where the workpiece is placed |
| **Wheel guard** | Covers wheel; protects operator |
| **Cross feed** | Moves wheel head up/down and left/right |
| **Traversing wheel** | Hand traverse, cross-slide, or vertical feed (3 types) |
| **Coolant nozzle** | Supplies coolant to reduce grinding heat |

### Operations
| Operation | Key point |
|---|---|
| Cylindrical grinding | Job mounted and rotated between centers |
| Taper grinding | Long job: swivel upper table. Short job: set wheel head to taper angle |
| Gear grinding | Generating process or form wheel |
| Thread grinding | Generating process or form wheel (single/multi thread) |

**Specs:** Wheel 350 × 32 × 127 mm (D×W×d) · Power ~3 HP · Max 3600 rpm (usually 1600–2500) · Weight ~800 kg
**Merits:** very high finish and accuracy, light pressure on work.
**Demerits:** expensive tools, slow (little by little removal), needs careful operation.
**Safety:** one operator only · wear mask for heavy grinding · **check wheel for cracks** · hands clear of wheel · stop motors before adjusting · guard stays fixed.

### Grinding Viva Q&A
1. **What type of cutting edges does grinding use?** Geometrically undefined, bonded abrasive grains.
2. **Why is coolant used?** Abrasive removal generates a lot of heat; coolant cools the job and wheel.
3. **What is the purpose of the wheel guard?** Protects the operator if the wheel breaks.
4. **What do you check before using a wheel?** Cracks (ring/tap test) and correct mounting.
5. **What do the wheel dimensions D×W×d mean?** Outer diameter × width × bore (hole) diameter.
6. **Live center vs dead center?** Live center rotates with the job (headstock); dead center is stationary (tailstock).
7. **How is taper grinding done on a long job?** By swiveling the upper table.
8. **How is fine positioning achieved?** Vernier-calibrated handwheel or NC/CNC control.
9. **Why is grinding slow?** Material is removed in tiny amounts by abrasive grains.
10. **When is grinding used?** Final finishing of cylindrical and flat surfaces to high accuracy.

## 4. Cross-Machine Quick Compare

| | Lathe | Shaper | Grinder |
|---|---|---|---|
| **Tool** | Single-point | Single-point | Abrasive wheel (multi-grain) |
| **Job** | Rotates | Fixed | Fixed or moves along path |
| **Tool motion** | Feed (linear) | Reciprocating | Rotating |
| **Main output** | Cylindrical, tapered, threaded | Flat, angular, slots | High-finish surfaces |
| **Power** | 1–2 HP | 3 HP | ~3 HP |

### Rapid-Fire Closers
- **Which machine has a quick-return?** Shaper.
- **Which has a split nut?** Lathe (in the apron).
- **Which gives the best surface finish?** Grinding.
- **Which cuts on one stroke only?** Shaper.
- **Which uses a coolant nozzle as a standard part?** Grinding.
- **Common safety rule for all three?** Stop the machine before adjusting, measuring or cleaning; keep guards in place.
